# 操作手册

## 1. 安装

1. 从 Releases 下载 `DeskTodo-<版本>-universal.dmg`（Apple Silicon 与 Intel 同一个包）。
2. 双击打开 dmg，把窗口里的 `DeskTodo.app` 拖进 `Applications`（窗口里有快捷方式）。
3. 第一次打开会被系统拦住（这个包没有做 Apple 公证）：到「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」，再确认一次。

不需要终端、不需要 Xcode。

备用命令（只在第 3 步的按钮找不到时用）：

```bash
xattr -dr com.apple.quarantine /Applications/DeskTodo.app
open /Applications/DeskTodo.app
```

## 2. 界面

- 主窗口是浮在桌面上的窄条；点右上角的箭头收起成桌面右下角的小圆点，点小圆点展开。
- 顶部一行：时钟、一句当天能核对的事实、进度环（今日划掉 / 总数）、收起箭头、菜单 `⋯`。
- 报告卡有五个页签：**今日 / 本周 / 30 天 / 半年 / 年度**。
- 菜单包含：数据来源、导出账本、恢复备份、备份自检、导出全部数据、清空全部数据、复制诊断信息、视图缩放、主题、开机启动、退出。

## 3. 四个动作

### 记

- 在输入框写一件，回车进清单。
- 清单可以挂到项目下（新建项目后，项目内回车）。
- 可以设一次性提醒或时间段提醒（例如每天 09:30，到某个结束日为止）。

### 划

- 点每行左侧的圆圈划掉；再点一次退账（账本里的那一笔也会退回来）。
- 「一键清除」只清走已经划掉的，不碰账本与历史。
- 拖过两天的任务会挂上「N 天」徽标；点徽标进欠账面板。

### 结

- 每天第一次打开，日程区顶部出现日结条：昨天划掉几件、今天还剩几件。点 ✕ 当天不再出现。
- 欠账面板可以：放回今天、推一天、销账（认赔）。

### 稽

- 报告卡五个页签都是只读账目。
- 每条来源行末尾的 `?` 可以纠正：数不对 / 不该显示 / 没事。「不该显示」会让该行永久消失，可在年度页恢复。
- 日级对账：某天日历有会但账本 0 件时，会问一次「没做事 / 忘了记 / 别问」。
- 月级投票：每月 1–7 号在年度页底部，可以给上个月的判断句投「准 / 不准」；同一类被投两次不准就永久静音。

## 4. 备份与恢复

备份在 `~/Library/Application Support/DeskTodo/backups/`：

- 触发点：升级后首次写入前、每次导出成功后、手动点「立即备份」。
- 轮转保留最近 5 份，文件名 `ledger.bak.<日期>T<时间>.json`。
- `index.json` 只记 `{file, sha256, bytes, entries, createdAt}`，不记任何内容。

恢复：菜单 →「恢复备份…」→ 选一份 → 应用会先把当前账本备份一次 → 恢复 → 提示条数变化。

备份自检：菜单 →「备份自检」，七项逐条显示通过或失败：

1. 目录存在且可写
2. 备份数 ≤ 5
3. 最新备份可解析
4. 最新备份条数与当前账本一致
5. 每份 sha256 与 index 一致
6. 账本非空但备份缺失时自动补一份
7. 最新备份早于 30 天时提醒

## 5. 导出账本

菜单 →「导出账本…」→ 选保存位置（默认 `ledger-<版本>-<日期>.json`）。

导出内容是账本原样 + `meta` 段：`exportedAt`、`appVersion`、`buildNumber`、`schemaVersion`。导出成功后自动触发一次备份。

## 6. 复制诊断信息

菜单 →「复制诊断信息」，写入剪贴板：

- 版本号、构建号
- macOS 版本、架构
- 备份自检结果
- 最近 50 行日志

脱敏在代码里做：用户名、邮箱、临时目录会被替换成占位符；不含任务内容、日历标题、文件名、App 名。贴给维护者即可。

## 7. 回滚到上一版

1. 先「导出账本…」留底。
2. 从 Releases 下载上一版 dmg（历史包标为 Pre-release）。
3. 拖进 Applications 覆盖，打开。

数据兼容规则：账本 `schemaVersion` 高于当前应用认识的版本时，应用只读、不写入，并给出可读原因；可以用「导出账本…」把原文件带走。

## 8. 清空全部数据

菜单 →「清空全部数据…」→ 选择「先导出，再清空」或「直接清空」。

清空范围：账本、快照、备份、日志、前台计时、偏好里的位置与城市缓存。不进废纸篓、不可撤销。

卸载：把 `DeskTodo.app` 拖进废纸篓；**数据默认保留**。要彻底干净：先清空全部数据，再删 app。

## 9. 已知限制

- 未做 Apple 公证：首次打开需要手动允许一次；升级后可能再允许一次。
- 仅 macOS 12 及以上；提供 universal 包（Apple Silicon + Intel）。
- 天气需要联网（`ipwho.is` 与 `open-meteo`），可在菜单里一键关掉，关掉后不再发起请求。
- 屏幕使用时间需要「完全磁盘访问」；不给也能用，只是少一行。
- 备份只保留最近 5 份；更长的历史请定期导出。

## 10. 自己验证

- **文件与签名**：`shasum -a 256 DeskTodo-<版本>-universal.dmg` 与 Release 页的 `SHA256SUMS.txt` 对照；`codesign --verify --strict` 应通过；`spctl` 对未公证包返回 rejected，属预期。
- **不联网**：菜单勾「不联网（天气停更）」→ `lsof -nP -a -p $(pgrep -f DeskTodo) -i` 应无输出。
- **数据**：`ledger.json` 是明文；菜单「导出账本…」得到可被文本编辑器打开的文件，含 `meta` 段。
- **备份**：菜单「备份自检…」应显示 7/7；`backups/index.json` 只记 hash、字节数、条数、时间。
- **诊断**：菜单「复制诊断信息」得到的内容不含任务正文；可自行搜索 `待办`、`title`、`task`，应为 0 处。

## 11. 常见问题

| 现象 | 处理 |
|---|---|
| 首次打开被拦，没有「仍要打开」 | 先点一次「打开」，再回「系统设置 → 隐私与安全性」找按钮 |
| 菜单栏图标/小圆点不见了 | 菜单栏图标被系统收进刘海区；点小圆点或 Dock 外的应用图标 |
| 日历/提醒事项没有数据 | 菜单 →「数据来源」→ 请求授权；被拒绝过就去系统设置里改 |
| 屏幕时间一行不出现 | 缺「完全磁盘访问」；到系统设置里把 app 删掉重加 |
| 升级后提示权限被重置 | 菜单 →「数据来源」→ 请求日历授权；完全磁盘访问需手动重加 |
| 账本文件读不出来 | 应用会只读打开并提示；用「导出账本…」带走原文件，再用备份恢复 |
| 两个窗口/两个小圆点 | 只允许一个实例；第二个会在启动时自行退出 |
| 想确认没有联网 | 菜单勾「不联网（天气停更）」，然后 `lsof -nP -a -p $(pgrep -f DeskTodo) -i` 应无输出 |
