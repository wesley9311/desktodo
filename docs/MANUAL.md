# 操作手册

> 这份文档只回答一个问题：**这个东西具体怎么用，每一步会发生什么。**
> 不含设计理由（那个在 `POSITIONING.md` 和 `PRODUCT-BOUNDARY.md`）。
>
> 写作标准：每一句都要能被使用者在屏幕上验证。写"会顺延"不算，
> 要写"点 → 会变成明天，并且那件身上多一个 N天"。
>
> 对应版本：1.3.1（下文所有位置、文案、行为都按这个版本核对过）

---

## 1. 它是什么

一句话：**你每天给自己派活，它把这一天记成一页账。**

一天一页，四个动作：**记**（写下今天要干的）、**划**（干完勾掉）、
**结**（今天到底结了几件）、**稽**（它记错了你能反驳）。

它不问"你还有什么没做"，它说"你欠自己多少、欠了几天"。

## 2. 它不是什么

- **不是任务管理器**。没有优先级、标签、看板、协作、同步。
- **不是计时器**。没有番茄钟，不会统计你"专注"了多久。
- **不联网**（除了天气，可一键关掉）。没有账号。
- **只有 macOS 12 及以上**。Windows 版不存在，原因见 `README.md`「支持平台」。

## 3. 装

### 3.1 第一次装

1. 下载 `DeskTodo-<版本>.zip`，双击解压。解压出来是**一个文件夹** `浮窗待办-<版本>/`，
   里面有四个东西：`浮窗待办.app`、`安装.command`、`读我.txt`、`体验清单.md`。
2. 在文件夹里找到 `安装.command`，**按住 Control 点它**（或右键）→ 选「打开」。
3. 系统弹一个窗，问你"确定要打开吗"。点「打开」。
4. 终端窗口跑几行字，最后一句是 `装好了，正在打开。` 然后应用自己起来。
5. 按任意键关掉那个终端窗口。

**如果双击 `安装.command` 而不是右键**：会弹「无法打开，因为 Apple 无法检查其是否包含恶意软件」，
按钮只有「移到废纸篓」和「取消」。点「取消」，回到第 2 步右键打开。
**这一步只需要做一次。**

### 3.2 装完应该看到什么

两样东西，缺一样就是没起来：

- **屏幕右上角菜单栏**，多了一个图标（不是 Dock，这个 app 没有 Dock 图标）。
- **桌面右下角**，一个直径约 10 点的小圆点，可以按住拖动。

如果两样都没有：打开「个人文件夹 → 应用程序」，双击 `浮窗待办`。
如果提示"文件已损坏"：说明解压不完整，重新下载。

### 3.3 第一次打开会被问两件事

| 弹窗 | 点「允许」会怎样 | 点「不允许」会怎样 |
|---|---|---|
| 访问「日历」 | 报告卡里多一行"今天 N 个日程"、年轮里多一行"有会 vs 没会"对照 | 那一行不出现，其余功能全在 |
| 访问「提醒事项」 | 报告卡里多一行"今天到期 N 件" | 同上 |
| 完全磁盘访问（不会自动弹，要手动开） | 报告卡里多一行"屏幕 5 小时 30 分" | 那一行不出现，其余功能全在 |

三项**都是只读**，没有任何一项允许它修改你的日历、提醒或文件。

### 3.4 升级

下载新 zip → 解压 → 双击 `安装.command`（升级时不用再右键，系统已经记住了）。

它会自己退出旧版、替换、重新打开。**记录一条都不会少**——
数据存在 `~/Library/Application Support/DeskTodo/`，不在 app 里面，替换 app 碰不到它。

### 3.5 卸载

把「个人文件夹 → 应用程序 → 浮窗待办」拖进废纸篓。

**记录不会跟着删。** 想彻底清干净：先打开它 → 右上角 `⋯` → 「清空全部数据…」→ 再删 app。

## 4. 界面：从上到下

浮窗宽度默认约 340 点，高度随内容变。下面按屏幕上的位置从上往下讲。

### 4.1 顶栏（可以按住拖动窗口）

```
15:20 42                  18°  ◔ 2/5        ⌃    ⋯
先啃硬的那块。
```

| 位置 | 是什么 | 点它会怎样 |
|---|---|---|
| 左边大数字 `15:20` | 当前时间，秒数在右上角小字 | 不能点 |
| 左边下面那行小字 | 一句随时段变的话（"先啃硬的那块"），15 分钟换一句 | 鼠标悬停能看到完整日期 |
| `18°` 天气胶囊 | 温度；有天气时显示 | 点一下立刻重新取天气 |
| `◔ 2/5` 进度环 | 今天完成 2 件 / 共 5 件 | **点一下打开报告卡** |
| `⌃` 箭头 | 收起 / 展开 | 切到紧凑日程，或切回完整清单 |
| `⋯` | 更多 | 打开系统菜单（见第 8 节） |

**窗口怎么拖**：按住顶栏空白处拖。
**窗口怎么改大小**：把鼠标移到窗口四边或两个下角，会出现调整光标，按住拖。
窗口右边和下边各有把手，上下左右都能拉。拉过之后高度就固定了，列表自己滚。
想回到"高度跟着内容走"：菜单 →「高度贴合内容」。

### 4.2 日结条（每天第一次打开时出现一次）

```
昨天结了 5 件 · 今天还剩 3 件              ✕
```

- 出现条件：昨天有记录（`daily` 里有数，或者那天 app 开着），**并且今天还没出现过**。
- 点 `✕` 收起。**不点也会消失**——它出现的那一刻就算"今天看过了"，
  当天关掉再打开不会再来一次。
- 昨天没有任何记录时，**这一行整条不出现**。它不会说"昨天你 0 件"。

### 4.3 欠账条（有拖过 2 天的任务时才出现）

```
有 3 件拖了 2 天以上              最久 8 天  看
```

点「看」或点整条 → 展开欠账面板：

```
欠账 · 3 件    最久 8 天              返回
8天   修落地页文案              [今天]  [销账]
4天   回李工的邮件              [今天]  [销账]
2天   看一眼竞品                [今天]  [销账]
销账 = 认下这件不做了。不算完成，也不再欠着。
```

| 按钮 | 做什么 | 结果 |
|---|---|---|
| `今天` | 把这件的日期拉回今天 | 它回到今天的清单里 |
| `销账` | 记一笔"认赔" | 它从清单消失，**不算完成**，年轮里单独记为「认赔 N 件」 |
| `返回` | 回今天的清单 | 关掉面板 |

销到最后一件时面板自动关闭，不会停在空页上。

### 4.4 报告卡（点进度环打开）

顶部五个页签：**今日 / 本周 / 30 天 / 半年 / 年轮**。

- 卡片高度**只增不减**：切到长页签会变高，切回短页签不会缩回去。
  这样窗口不会每次切页签都弹一下。
- 卡片内容超过 640 点时自己滚，不会把窗口顶出屏幕。
- 右上角「收起」关闭报告卡。

五个页签各看什么：

| 页签 | 看什么 |
|---|---|
| **今日** | 完成率环、已完成/待办/连续天数、近 7 天柱、今天的日历与屏幕时间、一句总结 |
| **本周** | 周一到**今天**（不是 7 天）、本周完成/动手的天/最猛一天 |
| **30 天** | 30 根柱、总计/动手的天/最猛一天 |
| **半年** | 182 天热力图、总计/有干活的天/最长连续 |
| **年轮** | 12 个月柱、新写/删掉/认赔、现在积压、项目占比、全年热力图、日历与提醒对照、一句判断、月级投票 |

**热力图怎么读**：

| 格子样子 | 意思 |
|---|---|
| 实心浅色 | 那天我知道，做了 0 件 |
| 实心深色（越深越多） | 那天做了几件 |
| **空心描边** | **那天我不知道**——不是 0 件 |
| 很淡的灰 | 那时候我还没开始记 |

鼠标悬停每一格会显示具体日期和件数，或者"没记录"。

### 4.5 输入框

```
写一件要办的事，回车添加          +
```

- 打字，**回车** → 加到今天的清单，光标留在输入框，可以连着写。
- 中文输入法选词时按回车**不会**误提交。
- `Esc` → 如果正在"写入某个项目"，取消那个目标；否则只是让输入框失去焦点。
- 上限 90 个字。

`+` 按钮点开有三个选项：

| 选项 | 做什么 |
|---|---|
| 新建待办 | 把输入框里的字提交（空的就只是聚焦输入框） |
| 从本地选择 | 选一个文件或文件夹，作为一条任务挂进来（点它能直接打开） |
| 新建空项目 | 建一个项目，名字先叫"未命名"，立刻进入改名状态 |

### 4.6 清单

每一行从左到右：

```
○  把落地页的第三屏重写      3天   ⏰   ←     ✕
```

| 元素 | 点它 | 双击它 |
|---|---|---|
| `○` / `✓` 圆圈 | 勾掉 / 取消勾选 | — |
| 标题文字 | — | **就地改名**，回车确认，Esc 取消 |
| 橙色的 `3天` | 打开欠账面板 | — |
| `明天`（日期标签） | 往后挪一天 | — |
| `⏰`（提醒） | 打开提醒设置 | — |
| 文件图标（如果这条挂了文件） | 用默认程序打开 | 换绑另一个文件 |
| `✕` | **直接删除，不二次确认** | — |

被勾掉的行会变灰、划掉，并沉到列表底部。

### 4.7 项目

```
▾  📁 落地页改版        2/5
      ○ 重写第三屏
      ○ 换主图
      + 在「落地页改版」里加节点，回车确认
```

- 点 `▾` 折叠 / 展开。
- 点文件夹图标：**单击打开**它绑定的文件夹（未绑定的会弹选择框），**双击**换绑。
- 最后那行行内输入框：直接回车就能往这个项目里加，加完焦点还留着，可以连着写。

**怎么把任务放进项目**：在项目里用那行输入框写。
**怎么把任务移出来**：目前没有"移动到"操作，只能删了重写。

### 4.8 底部

```
还剩 3 件事 · 2 项已完成              一键清除 2
```

- 左边：当前清单的统计（注意：这和报告卡的「今日」不是一回事，它数的是**整个清单**）。
- 右边「一键清除 N」：把**已勾选完成**的 N 项从清单删掉。
  **账本里的数字不会变**——清掉的只是条目，那几件仍然算做过（见 7.2）。

### 4.9 提醒响了

```
⏰ 回李工的邮件
```

横幅出现在输入框下面，同时系统通知也会响一次。点横幅打开那条任务。

### 4.10 收起态（点 ⌃ 箭头）

变成一个窄条，只放今天的日程：

```
今天 2/5 · 还剩 3 件
昨天结了 5 件 · 今天还剩 3 件     ✕
有 3 件拖了 2 天以上            看
○ 把落地页的第三屏重写   3天  → ⏰ ✕
○ 回李工的邮件
点箭头展开全部
```

收起态和展开态**共用同一份数据**，勾一件两边都变。
区别只是展开态显示完整清单（含项目），收起态只显示今天要做的。

## 5. 四个动作，具体怎么做

### 5.1 记

1. 在输入框写一句，回车。**默认加到今天。**
2. 想加到某个项目：点项目里那行 `+ 在「…」里加节点`，写完回车。
3. 想加一个已经存在的文件：`+` →「从本地选择」→ 选文件。
   任务名取文件名（去掉扩展名），点文件图标能直接打开它。

### 5.2 划

点左边的圆圈。三种后果：

- 任务变灰、沉底，`daily` 那天 +1，进度环走一格。
- 如果它是当天最后一件，**收起态会自动接到明天**（如果你有排在明天的）。
- **取消勾选**：再点一次，`daily` 那天 −1，任务回到未完成。

> 一个边界：一件 60 天前完成的任务，取消勾选时账本能退回来，
> 但"什么时段出活"那个统计退不回去（明细只留 60 天）。账目数字不受影响。

### 5.3 结

**没有"结算"按钮。** 结账是自动的，出现在两个地方：

- **日结条**：每天第一次打开，报昨天结了几件。
- **报告卡**：随时看今天/本周/30 天/半年/今年的账。

一条重要规则：**"没记录"不等于"0 件"。** 那天没开过 app、也没任何操作，
图表里会画成空心描边，提示写"没记录"。它不会替你判断那天你到底干没干。

### 5.4 稽（反驳它）

这是这个产品最特别的一块。三个层级，从细到粗：

**第 1 层：行级「?」**
报告卡里每一行来源数据（日历、提醒、屏幕）右边有个 `?`。点开三个选项：

| 选项 | 结果 |
|---|---|
| 数不对 | 记一笔"你纠正过我"，**这个数不会改**（改了就是假账） |
| 不该显示 | 这一行永久消失。年轮页底部会出现"把那 N 行放回来" |
| 没事 | 关掉 |

**第 2 层：日级对账**
当"今天日历上有 ≥2 个日程，但账本 0 件"时，今日页会出现一句问话：

```
今天日历上有 3 个日程，账本 0 件。   [没做事] [忘了记] [别问]
```

- 「没做事」：确认那天确实是 0，写进 `gap`。
- 「忘了记」：承认漏记。**它不会替你补数**，只是标一下"这天可能漏记"。
- 「别问」：14 天内不再问。

**第 3 层：月级否决**
每月 1–7 号，在**年轮**页签底部，会把上个月它说过的判断句逐条列出来，每条可以投「准 / 不准」。

**同一类判断被投两次「不准」，以后就只给数、不给话。**

> 注意：这一层要求你上个月打开过年轮页签（它只在年轮页渲染时记录自己说过什么）。
> 如果你不看年轮，就没有可投的东西。

## 6. 提醒

点任务右边的 `⏰` 打开设置抽屉。两种：

| 类型 | 怎么设 | 行为 |
|---|---|---|
| **定时** | 选"今天 / 明天 / 后天 + 时刻" | 到点响一次 |
| **时间段** | 选起止日期 + 每天的时刻 | 每天那个点响，直到结束日 |

规则：

- 到点会响：系统通知弹一次，窗口里输入框下面同时出现一条横幅。
- 如果关着窗口错过了，**6 小时内打开还会补响**；超过 6 小时，单次提醒直接标成"已响"，
  时间段提醒则顺延到下一个时刻。
- 勾掉任务时提醒自动取消。
- 任务行上的 `⏰` 会显示状态：`5 分钟后`、`14:30`、`7/12 14:30`、`已响`、`已结束`。

## 7. 数据

### 7.1 存在哪

```
~/Library/Application Support/DeskTodo/
├── data.json                      主文件，纯文本 JSON
├── data.json.bak                  上一版，自动留
├── data.corrupt-<时间>.json       只有读出问题时才出现（坏的那份留证）
└── focus.json                     前台 app 计时（只有这一项，不含任务）
```

文件权限是 `600`（只有你这个账户能读）。想自己看一眼：

```bash
open ~/Library/Application\ Support/DeskTodo/data.json
```

### 7.2 带走

菜单 →「导出全部数据…」→ 得到一个 zip：

```
data.json      全部原始数据
读我.md        格式版本、逐年数字、字段表、三条口径声明
```

`读我.md` 是给**不装这个 app 的人**看的：把这个 zip 发给别人，他能自己回答
"这几年干了多少、从哪天开始记的"。

### 7.3 恢复

把 `data.json` 放回 `~/Library/Application Support/DeskTodo/`，重新打开即可。
整个文件夹可以直接替换。

如果主文件读不出来，启动时会自动用 `data.json.bak` 恢复，并把坏的那份改名成
`data.corrupt-时间.json` 留着，**不会覆盖**。屏幕上会出现一条橙色提示，告诉你发生了什么。

### 7.4 删除

菜单 →「清空全部数据…」。**真删**：主文件、备份、留证文件全删，不进废纸篓，不留副本。

清空之后 `id` 计数器也回到 1——不留"你以前建过 57 个条目"的痕迹。

## 8. 菜单（`⋯`）逐项

### 8.1 显示

| 项 | 作用 | 快捷键 |
|---|---|---|
| 展开完整清单 / 收起为紧凑日程 | 切换展开态和收起态 | — |
| 收起悬浮窗（留个桌面小圆点） | 整个窗口收成桌面右下角一个点 | `⌘H` |
| 收起后的小圆点 → 七种颜色（蓝 / 绿 / 橙 / 粉 / 紫 / 青 / 石墨） | 改那个点的颜色 | — |
| 外观 → 跟随系统 / 浅色 / 深色 | 主题 | — |

### 8.2 天气

| 项 | 作用 |
|---|---|
| 天气城市 → 自动定位（按 IP） | 用 `ipwho.is` 猜你在哪个城市 |
| 天气城市 → 手动填写城市… | 自己输城市名，用 `open-meteo` 的地理编码查 |
| **不联网（天气停更）** | **勾上之后，除天气以外的功能全部照常，但一个网络请求都不会发** |

「不联网」勾上后，天气胶囊直接消失（不是显示上次的温度——那样会被当成还在更新）。
除天气以外的功能全部照常，只是没有温度。

验证它真的没联网：

```bash
lsof -nP -a -p $(pgrep -f DeskTodo) -i     # 没有任何输出
```

### 8.3 数据来源

| 项 | 作用 |
|---|---|
| 日历：ok / ask / denied | 只读状态，不能点 |
| 请求日历授权… | 弹系统授权框（以前的拒绝也能重新问） |
| 提醒事项：… / 请求提醒事项授权… | 同上 |
| 屏幕使用时间：… | 只读状态 |
| 打开「完全磁盘访问」设置… | 跳系统设置，自己把开关打开 |
| 前台 App 计时：运行中（不需要授权） | 只读 |
| 立即刷新数据 | 重新读一次日历/提醒/屏幕 |

状态含义：`ok` 拿到了 · `ask` 还没问过 · `denied` 被拒绝 · `nofda` 缺完全磁盘访问 ·

## 10. 键盘能做什么（完整清单）

**没有全局快捷键。** 这个 app 不监听任何系统级键盘事件。

窗口在前台时可用：

| 键 | 作用 |
|---|---|
| `回车` | 提交输入框（或确认改名） |
| `Esc` | 取消"写入某项目"目标 / 退出改名 / 让输入框失焦 |
| `⌘H` | 收起为桌面小圆点（**不是系统的"隐藏应用"**，是这个 app 自己的菜单项占用了这个组合） |
| `⌘T` | 切换始终置顶（菜单项快捷键） |
| `⌘Q` | 退出 |

**鼠标右键被禁用**（这个窗口里右键不会弹任何菜单）。
所有操作都靠左键：单击、双击（改名 / 换绑）、拖动（窗口 / 圆点 / 边缘）。

> 已知欠账：相当一部分操作只能用鼠标，没有纯键盘路径。这一条写在 `CONTRIBUTING.md` 的"可加"里。

## 11. 出问题了怎么办

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 双击 `安装.command` 被拦 | Gatekeeper，没买 Apple 公证 | 点「取消」→ 右键 →「打开」→ 再点「打开」 |
| 装完找不到窗口 | 它没有 Dock 图标 | 看右上角菜单栏，或桌面右下角；都没有就去「个人文件夹 → 应用程序」双击 |
| 屏幕上有一行橙色的「数据文件读不出来」 | 主文件坏了，或权限不对 | 点那行的「看文件」，坏的那份会留着（`data.corrupt-时间.json`），用备份恢复 |
| 说"保存失败：这次改动没写进磁盘" | 磁盘满、目录不可写、权限被杀 | 先菜单「打开数据文件夹」确认能写；腾空间；再改一次任一条目触发重存 |
| 日历那两行一直不出现 | 授权是 `ask` 或 `denied` | 菜单 →「数据来源」→ 看状态 →「请求日历授权…」；被拒过就先在系统设置里打开 |
| 屏幕时间那行不出现 | 缺「完全磁盘访问」 | 菜单 →「数据来源」→「打开完全磁盘访问设置…」→ 把开关打开 → 重启 app |
| 天气一直是空的 | 没网，或者勾了「不联网」 | 取消勾选「不联网」；菜单 →「天气城市」→「手动填写城市…」 |
| 窗口比屏幕还高 | 手动拉过尺寸 | 菜单 →「高度贴合内容」 |
| 报告卡里的数字和底部对不上 | 底部数的是**整个清单**，报告卡数的是**今天** | 这是两个不同的数，不是 bug（见 4.8） |
| 勾掉又取消勾选，今天的数变了 | 正确行为 | `daily` 跟着退回去，账本只记真实 |

## 12. 常见问题

**Q：能不能同步到手机 / 另一台 Mac？**
不能，也不会做。数据只在你这台机器的硬盘上。想带走用「导出全部数据…」。
原因见 `CONTRIBUTING.md` 的不可加清单。

**Q：为什么删掉一条任务，报告里的数字不变？**
删除和"没做过"是两件事。如果它没做完就被删，会记进「删掉」；
如果做完了再删，那件仍然算完成。删除只清条目，不动账本。

**Q："顺延 3 天"是什么意思？**
这件任务跨了 3 次夜没做完。系统每天跨夜时自动 +1，不是你自己设的日期。
拖到 2 天以上，任务行右边会出现橙色 `N天`，点它可以直接处理（放回今天或销账）。

**Q：销账和删除有什么区别？**
删除是"我不想要这条了"，销账是"我认下这件事不做了"。
销账不算完成，但也不再欠着，而且年轮里单独记一笔「认赔 N 件」。
删除更含糊，所以两者分开记。

**Q：为什么它不催我？**
催是清单软件做的事。这个产品只记账：它告诉你欠了多少、欠了几天，不告诉你"该努力了"。

**Q：连续天数为什么断了？**
只数"我确实看得见并且有产出"的日子。中间有一天它没开着、也没有任何记录，
它就当作不知道，不当成 0——所以那一串会断在"我不知道"那里。
所以这个数**永远是下界**，真实值只会更长。

**Q：它会知道我打开了它几次吗？**
不知道。没有任何上报。`seen` 只记"这一天开过"，不记次数、不记时长、不记任何内容。

## 13. 三件最好现在就知道的事

1. **第一次装必须右键打开。** 只需要一次，之后正常双击。
2. **数据是一个 JSON，删了就是没了。** 想留底就定期「导出全部数据…」。
3. **"没记录"不是"0 件"。** 图表里的空心格是真话，不是缺陷。
